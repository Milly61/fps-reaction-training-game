# FPS Reaction Training Game

## Project Overview

FPS Reaction Training Game is an easy to create interactive game using Microsoft MakeCode Arcade. It's crafted for gamers that enjoy FPS with an opportunity to work on their reflexes, aim and focus before being able to play a Valorant 1v1 match.

It was my personal passion in FPS gaming which initiated this idea. What I wanted to do was look at ways in which programming basics could be used to make a mini and fun warm up exercise!

## How to Play

Read the READY and GO messages, and start the game.

To move the crosshair press the arrow keys.

Press B to fire shot when crosshair on red target.

These hits are a point each, if they are made.

Once it is hit, the hit target will move to another random location.

Other sound can be heard if the shot is missed.

Work on getting as many points as you can, with the 30-sec timer.

## Main Features

Crosshair Movement

The title is based on a games console control, with a crosshair sprite controlled by the player. The cross hair remains inside the screen.

Target Detection

A conditional statement is used to determine if the crosshair is over the target, when B is pressed.

Scoring System

If a hit is made a point is added to the score. The target then moves to another position, which is randomly generated.

Audio Feedback

Varying sounds of successful and unsuccessful shots, to make players understand what the result of each shot was.

Countdown Timer

Another reaction training challenge is being given by a 30 second's countdown. When the Timer Counts Down to ZERO, the game is over.

## How the Code Works

Several important programming concepts are used in the project:

Variables: Point at other sprites (the target & the crosshair).

Events: When player presses B-button.

Conditional statements: Conditional statements that test if the cross hair is above and/or under the target.

Random numbers: Create new “go to” locations.

Functions: Regulate the movement, scoring, sounds and countdown timer for the sprites.

All these features combine to give an interactive gameplay that reacts to players' input.

Development and Learning

In the process of development, I got some experience in making sprites, listening to controller actions, doing conditional programming, and randomly generating positions.

An important component in the development was being able to correlate the shooting action to the overlap condition. This allowed me to get a real idea on how input from the player, logical decisions and visual feedback all tie in together.
